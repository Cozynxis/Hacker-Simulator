# Hacker Simulator — Shadow OS

A fictional, offline-first desktop story game for browsers.

## Play
Open index.html locally or enable GitHub Pages (Settings → Pages → Deploy from branch → main / root).

## Features
- Shadow OS desktop, draggable windows, taskbar, clock
- Synthesized sound effects via Web Audio API (no external assets)
- Animated UI and reduced motion toggle
- Guided tutorial
- Chapter 01: The First Message, puzzle and demo school database
- GhostChat, Terminal, Missions, Files, Wallet, Upgrades, Settings
- XP, levels, credits and automatic localStorage saving
- Responsive layout; no dependencies, no server

## Safety and scope
All accounts, grades, money, targets and terminal commands are fictional in-game objects. There are no real network requests, credential collection or payment actions.

## Roadmap
More chapters, branching dialogue, audio soundtrack, achievements, richer OS interactions and accessibility improvements.
